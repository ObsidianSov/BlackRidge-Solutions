Security

Security is a core part of the BlackRidge identity.

Development should avoid committing:

- API keys
- Passwords
- Authentication tokens
- Private credentials
- Environment secrets
- Personal information
- Production configuration secrets

Sensitive configuration should be stored through environment variables or an appropriate secret-management system.

If a backend is introduced, authentication, authorization, input validation, logging, rate limiting, and secure data handling should be considered from the beginning.
